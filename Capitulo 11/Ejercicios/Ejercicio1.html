Ejercicio de autoevaluación: Capítulo 11

11.1 Complete las siguientes oraciones:

  1. Como JavaScript usa objetos para realizar muchas tareas, se conoce por lo común como ________________.
    Respuesta: lenguaje de programación basado en objetos.
  2. Todos los objetos tienen ________________ y exhiben ________________.
    Respuesta: atributos, comportamientos.
  3. Los métodos del objeto ________________ nos permiten realizar muchos cálculos matemáticos comunes.
    Respuesta: Math.
  4. Al proceso de invocar (o llamar) al método de un objeto se le conoce como ________________.
    Respuesta: enviar un mensaje al objeto.
  5. Las literales de cadena o constantes de cadena se escriben como una secuencia de caracteres en ________________ o ________________.
    Respuesta: comillas dobles, comillas sencillas.
  6. Los índices para los caracteres en una cadena empiezan en ________________.
    Respuesta: 0.
  7. Los métodos ________________ y ________________ de String buscan la primera y última ocurrencias de una subcadena en un objeto String, respectivamente.
    Respuesta: indexOf, lastIndexOf.
  8. Al proceso de dividir una cadena en tokens se le denomina ________________.
    Respuesta: tokenización.
  9. El procesamiento de fechas y horas puede realizarse con base en la ________________ o en el ________________ del Estándar de Tiempo Mundial.
    Respuesta: zona horaria local de la computadora, Tiempo Universal Coordinado (UTC).
  10. El método ________________ de Date recibe como argumento una cadena que representa una fecha y hora, y devuelve el número de milisegundos transcurridos entre la medianoche del 1 de enero de 1970 y la fecha y hora especificadas.
    Respuesta: parse.
  11. Las aplicaciones Web pueden usar la propiedad ________________ del objeto window para almacenar hasta varios megabytes de datos de cadenas de pares clave/valor en la computadora del usuario y pueden acceder a estos datos a través de sesiones y pestañas del navegador.
    Respuesta: localStorage.
  12. Las aplicaciones Web que necesitan acceso a los datos de pares clave/valor para sólo una sesión de navegación y que deben mantener esos datos separados entre varias pestañas pueden usar la propiedad ________________ del objeto window.
    Respuesta: sessionStorage.
  13. Un selector ________________ de CSS3 selecciona el primer hijo de un elemento.
    Respuesta: :first-child.
  14. Un selector ________________ de CSS3 con el argumento "odd" selecciona los elementos hijos impares y uno con el argumento "even" selecciona los elementos hijos pares.
    Respuesta: nth-child.
