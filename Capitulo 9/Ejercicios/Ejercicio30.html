9.30 ¿Qué hace la siguiente función?

function misterio( a, b )
{
    if ( b == 1 )
        return a;
    else
        return a + misterio( a, b - 1 );
}
Explicación: La función realiza la multiplicación de dos números enteros $a$ y $b$ (asumiendo que $b$ es un entero positivo) mediante sumas sucesivas usando recursividad. En cada llamada recursiva suma $a$ y disminuye $b$ en 1 hasta llegar al caso base ($b == 1$), lo cual equivale matemáticamente a calcular $a \times b$.
