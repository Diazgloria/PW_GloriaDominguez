Ejercicios de autoevaluación: Capítulo 9

9.5 Localice el error en cada uno de los siguientes segmentos de programa y explique cómo corregirlo:

  1. Error: method no es la palabra clave que se utiliza para comenzar la definición de una función[cite: 16].
    Corrección: Cambiar method a function[cite: 16]. 
    function g() {
    document.writeln("Dentro del método g");
}
  2. Error: Se supone que la función debe devolver un valor, pero no hay instrucción return[cite: 16].
    Corrección: Eliminar la variable resultado y colocar la instrucción return x + y; o agregar return resultado; al final del cuerpo[cite: 16]. 
    function suma(x, y) {
    return x + y;
}
  3. Error: El punto y coma después del paréntesis derecho que encierra la lista de parámetros es incorrecto[cite: 16].
    Corrección: Eliminar el punto y coma después del paréntesis derecho de la lista de parámetros[cite: 16]. 
    function f( a ) {
    document.writeln( a );
}
