Ejercicios de autoevaluación: Capítulo 6

6.11 ¿Qué aparece en el diálogo de alerta cuando se ejecuta cada una de las siguientes instrucciones de JavaScript? Asuma que $x = 2$ y $y = 3$.

  1. window.alert("x = " + x);
    A) x = 2
    B) x = x
    C) 2 = 2
    D) Error de sintaxis
    Respuesta correcta: A) x = 2
  2. window.alert("El valor de x + x es " + (x + x));
    A) El valor de x + x es 22
    B) El valor de x + x es 4
    C) El valor de x + x es x + x
    D) 4
    Respuesta correcta: B) El valor de x + x es 4
  3. window.alert("x =");
    A) x = 2
    B) 2
    C) x =
    D) Error
    Respuesta correcta: C) x =
  4. window.alert(x + y + " = " + (y + x));
    A) 2 + 3 = 3 + 2
    B) 5 = 5
    C) 23 = 5
    D) Error
    Respuesta correcta: B) 5 = 5
