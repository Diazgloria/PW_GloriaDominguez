6.13 Dada y = a * x * x * x + 7, ¿cuáles de las siguientes instrucciones de JavaScript son correctas para esta ecuación?

  1. y = a * x * x * x + 7;
  2. y = a * x * x * (x + 7);
  3. y = (a * x) * x * (x + 7);
  4. y = (a * x) * x * x + 7;
  5. y = a * (x * x * x) + 7;
  6. y = a * x * (x * x + 7);

Respuestas correctas: a), d) y e)
