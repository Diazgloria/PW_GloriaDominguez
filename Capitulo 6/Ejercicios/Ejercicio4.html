Ejercicio 6.4: Identificación y corrección de errores

A continuación se detallan los errores encontrados en cada instrucción y su respectiva corrección:

Inciso a)

Instrucción original con error: 
if (c < 7);
    window.alert("c es menor que 7");

Error: El punto y coma (;) al final del if cierra la condición de inmediato, haciendo que la instrucción del cuadro de diálogo se ejecute siempre por separado.

Instrucción corregida: 
if (c < 7) {
    window.alert("c es menor que 7");
}

Inciso b)

Instrucción original con error: 
if (c => 7)
    window.alert("c es igual o mayor que 7");

Error: El operador correcto en JavaScript para "mayor o igual que" es >=, no =>.

Instrucción corregida: 
if (c >= 7) {
    window.alert("c es igual o mayor que 7");
}
