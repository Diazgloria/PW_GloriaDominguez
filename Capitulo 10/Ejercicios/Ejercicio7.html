Ejercicios: Capítulo 10

10.7 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué.

  1. Para hacer referencia a una ubicación o elemento específico en un arreglo, especificamos el nombre del arreglo y el valor del elemento.
    Respuesta: Falso. Se especifica el nombre del arreglo y la posición o subíndice (índice) del elemento.
  2. La declaración de una variable reserva espacio para un arreglo.
    Respuesta: Falso. Para reservar espacio para un arreglo se debe inicializar utilizando la sintaxis de corchetes [] o instanciarlo mediante new Array().
  3. Para indicar que deben reservarse 100 ubicaciones para el arreglo entero p, el programador debe escribir la siguiente declaración: p[ 100 ];
    Respuesta: Falso. La forma correcta de instanciar un arreglo de 100 elementos es var p = new Array( 100 ); o declarando sus valores.
  4. Un programa de JavaScript que inicializa los elementos de un arreglo de 15 elementos en cero debe contener cuando menos una instrucción for.
    Respuesta: Falso. Se pueden inicializar directamente al declarar el arreglo usando la sintaxis literal: var a = [0, 0, 0, ...]; o mediante otros métodos iterativos o de llenado como fill().
  5. Un programa de JavaScript que calcula el total de los elementos de un arreglo bidimensional debe contener instrucciones for anidadas.
    Respuesta: Falso. Aunque usar dos ciclos for anidados es la forma habitual de recorrer filas y columnas, también se pueden emplear métodos modernos de arreglos como flat() y reduce() sin anidar instrucciones for explícitas.
