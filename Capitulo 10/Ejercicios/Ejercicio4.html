10.4 Escribir instrucciones de JavaScript (con respecto al arreglo tabla) para realizar cada una de las siguientes tareas:

  1. Declarar y crear el arreglo con tres filas y tres columnas.
    Respuesta: 
    var tabla = new Array( new Array( 3 ), new Array( 3 ), new Array( 3 ) );
  2. Almacenar el número total de elementos en la variable totalElementos.
    Respuesta: var totalElementos = tabla.length * tabla[ 0 ].length;
  3. Usar una instrucción for...in para inicializar cada elemento del arreglo con la suma de sus índices de fila y de columna. Suponga que las variables x y y se declaran como variables de control.
    Respuesta: 
    for ( var x in tabla )
{
   for ( var y in tabla[ x ] )
   {
      tabla[ x ][ y ] = parseInt(x) + parseInt(y);
   }
}
