Ejercicios de autoevaluación: Capítulo 7

7.7 Identifique y corrija los errores en cada uno de los siguientes segmentos de código:

  1. Error: Se usa la palabra incorrecta mH11 en lugar de while, una flecha <- inválida en lugar de un operador de comparación o menor igual (<=), un operador de asignación múltiple * - en lugar de *=, y falta un punto y coma en el incremento ++c:.
    Código corregido: 
    while (c <= 5) {
                            producto *= c;
                            ++c;
                        }
  2. Error: Se utiliza un punto y coma después de else, lo que termina prematuramente la estructura condicional y provoca que la siguiente instrucción se ejecute siempre de forma independiente. Además, el operador de asignación — es incorrecto para una comparación (debe usarse == o ===).
    Código corregido: 
    if (genero == 1) {
                            document.writeln("Mujer");
                        } else {
                            document.writeln("Hombre");
                        }
