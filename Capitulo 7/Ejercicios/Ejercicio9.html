Ejercicios de autoevaluación: Capítulo 7

7.9 Identifique y corrija los errores en cada uno de los siguientes segmentos de código:

  1. Error: Hay un punto y coma al final de la instrucción if ( edad >= 65 );, lo que cierra la condición prematuramente haciendo que el bloque siguiente se ejecute siempre. Además, falta la llave de apertura { para agrupar las instrucciones del else si fueran múltiples (o bien estructurarlo correctamente).
    Código corregido: 
    if ( edad >= 65 ) {
                            document.writeln("Edad es mayor o igual que 65");
                        } else {
                            document.writeln("Edad es menor que 65");
                        }
  2. Error: La variable total no está inicializada (su valor inicial es undefined), por lo que al intentar sumarle un número con += el resultado será NaN (Not a Number). Debe inicializarse en 0.
    Código corregido: 
    var x = 1, total = 0;
                        while ( x <= 10 ) {
                            total += x;
                            ++x;
                        }
  3. Error: El ciclo while no tiene llaves {} delimitando su cuerpo, por lo que solo la instrucción total += x; forma parte del ciclo y el incremento ++x; queda fuera, provocando un bucle infinito.
    Código corregido: 
    var x = 1;
                        var total = 0;
                        while ( x <= 100 ) {
                            total += x;
                            ++x;
                        }
  4. Error: La variable y se inicializa en 5 y dentro del ciclo se incrementa con ++y; (pasando a 6, 7, 8...). Como la condición es y > 0, el número seguirá creciendo indefinidamente, provocando un bucle infinito (debió decrementar con --y;).
    Código corregido: 
    var y = 5;
                        while ( y > 0 ) {
                            document.writeln( y );
                            --y;
                        }
