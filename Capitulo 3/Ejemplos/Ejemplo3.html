Java How to Program, 9/e

De Java How to Program, 9/e

Caracteristicas:

  • Extensa cobertura de los fundamentos: dos capitulos sobre instrucciones de control
  • Enfoque en ejemplos del mundo real
  • Conjunto de ejercicios Hacer la diferencia.
  • Introduccion desde los primeros articulos a las clases, objetos, metodos y cadenas
  • Manejo de excepciones integrado
  • Archivos, flujos y serializacion de objetos
  • Secciones modulares opcionales sobre el lenguaje y caracteristicas de la biblioteca de la nueva version Java SE 7
  • Otros temas: Recursividad, busqueda, ordenamientos, colecciones genericas, genericos, estructuras de datos, applents, multimedia, multihilos, bases de datos, desarrollo de aplicaciones web, servicios web y un caso de estudio opcionalde diseño orientado a objetos con un ATM.
