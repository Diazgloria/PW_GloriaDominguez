Ejercicios de autoevaluación: Capítulo 8

8.2 Escriba una instrucción o un conjunto de instrucciones en JavaScript para realizar cada una de las siguientes tareas:

  1. Sumar los enteros impares entre 1 y 99. Utilice una instrucción for. 
    suma = 0;
                        for ( cuenta = 1; cuenta <= 99; cuenta += 2 )
                            suma += cuenta;
  2. Calcular el valor de 2.5 elevado a la potencia de 3. Use el método pow. 
    Math.pow( 2.5, 3 );
  3. Imprimir los enteros del 1 al 20 mediante el uso de un ciclo while y la variable contador x. 
    x = 1;
                        document.writeln( "<p>" );
                        while ( x <= 20 ) {
                            document.write( x + " " );
                            if ( x % 5 == 0 )
                                document.write( "</p><p>" );
                            ++x;
                        }

  4. Replica el ejercicio 8.2, (c), pero ahora use una instrucción for. 
    document.writeln( "<p>" );
                        for ( x = 1; x <= 20; x++ ) {
                            document.write( x + " " );
                            if ( x % 5 == 0 )
                                document.write( "</p><p>" );
                        }
                        document.writeln( "</p>" );
